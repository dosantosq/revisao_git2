Teclas de Atalho do Visual Studio Code

Arquivos e Navegação

Ctrl + P Abre o painel de arquivos para localizar rapidamente um arquivo.
Ctrl + Shift + P Abre a paleta de comandos do VS Code.
Ctrl + Tab Alterna entre arquivos abertos.
Ctrl + B Abre/fecha a barra lateral.
Ctrl + J Abre/fecha o painel de terminal e outras áreas.

Edição

Ctrl + X Recorta a linha ou seleção atual.
Ctrl + C Copia a linha ou seleção atual.
Ctrl + V Cola o conteúdo copiado.
Ctrl + Z Desfaz a última ação.
Ctrl + Shift + Z Refaz a última ação.
Alt + ↑ / ↓ Mova a linha para cima ou para baixo.

Busca e Substituição

Ctrl + F Busca no arquivo atual.
Ctrl + H Abre a substituição de texto.
Ctrl + Shift + F Pesquisa em toda a pasta/projeto.
F2 Renomeia o símbolo selecionado.

Seleção e Código

Shift + Alt + ↓ Duplica a linha atual para baixo.
Ctrl + / Comenta ou descomenta a linha atual.
Shift + Alt + F Formata o documento inteiro.
Ctrl + Space Ativa sugestões de autocompletar.
F12 Vai para a definição do símbolo.

Terminal e Depuração

Ctrl + ` Abre/fecha o terminal integrado.
F5 Inicia a depuração.
Shift + F5 Para a depuração.
F9 Alterna breakpoint na linha atual.

Gerais

Ctrl + S Salva o arquivo atual.
Ctrl + Shift + S Salva todos os arquivos.
Ctrl + W Fecha a aba atual.
Ctrl + Shift + T Reabre a última aba fechada.
Dica: Muitos atalhos podem variar conforme a extensão ou sistema operacional, mas estes são os mais usados no VS Code.
